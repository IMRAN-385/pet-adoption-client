# 🐾 Pet Adoption Platform

A full-stack MERN application that allows users to explore pets available for adoption, submit adoption requests, and manage pet listings through a secure dashboard. Pet owners can manage their listings and approve or reject adoption requests, while users can track the status of their requests.

# 🚀 Features

- Secure authentication using Better Auth (Email/Password & Google Login)
- Browse all available pets with search, filter, and sorting functionality
- View complete pet details before submitting an adoption request
- Add, update, and delete pet listings from the dashboard
- Manage adoption requests with approve and reject functionality
- Prevent pet owners from requesting adoption of their own pets
- JWT authentication with HTTPOnly cookies for protected routes
- Responsive UI for Mobile, Tablet, and Desktop
- Loading spinner and custom 404 page
- Toast notifications for all CRUD operations

# 📂 Installation

### Clone the repositories

```bash
git clone https://github.com/IMRAN-385/pet-adoption-client.git
git clone https://github.com/IMRAN-385/pet-adoption-server.git
```

### Install Client

```bash
cd pet-adoption-client
npm install
npm run dev
```

### Install Server

```bash
cd pet-adoption-server
npm install
npm run dev
```
